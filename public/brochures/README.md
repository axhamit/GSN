# Course Brochures

This directory should contain PDF brochures for each course.

## Required Brochures

1. **advanced-agentic-ai-brochure.pdf** - Brochure for Advanced Agentic AI and Generative AI course
2. **applied-ai-master-brochure.pdf** - Brochure for Applied AI Master Certification course
3. **career-launch-academy-brochure.pdf** - Brochure for Career Launch Academy course

## Instructions

Replace this README file with actual PDF brochures. The brochure download functionality is implemented and will automatically download the correct brochure based on the course when a user submits an enquiry form.

## File Naming Convention

Brochure files should be named as: `{course-slug}-brochure.pdf`

For example:
- `advanced-agentic-generative-ai` → `advanced-agentic-ai-brochure.pdf`
- `applied-ai-master-certification` → `applied-ai-master-brochure.pdf`

## Note

The brochure download is triggered after successful form submission. If a brochure file does not exist, the download will fail silently. Ensure all brochure files are present before going to production.
